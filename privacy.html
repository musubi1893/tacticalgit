Tacitical GIT AI Privacy Policy

Last updated: September 18, 2026

Tacitical GIT AI is a private application used to automate a Hermes AI Agent to the application owner's Google Drive.

Google User Data

The application accesses Google Drive for the purpose of creating, storing, retrieving, and managing Hermes Agent backup files.

Use of Data

Google user data is used solely to provide backup functionality requested by the application owner.

Data Sharing

Google user data is not sold, rented, or shared with third parties.

Data Storage

Backup files are stored in the application owner's Google Drive. OAuth authorization credentials may be stored by the application to permit automated backups.

Data Deletion

The application owner can delete backup files directly from Google Drive and revoke the application's Google account access at any time.
